# 对照纪律地图 · 预注册（接触数据之前写死）

> 2026-08-12。今天第五份这种文件（前四份：材料 / 天文 / 组合 / 文献连接）。
> 规则先于数据。今天已经有一次「8 条检索式全 0，差点报成没人做过」，靠先验仪器抓住的。

## 要测什么

**一个研究领域，在它自己的话语里，有多少「对照纪律」？**

今天实测出一个点：6,422 篇「materials discovery」论文，标题+摘要提到
`positive control` / `negative control` 的 **0 篇**，而同一个词在 drug discovery 里 388 篇、
生物学全领域 101,239 篇；同时 `false positive` 24 篇 vs `false negative` **1 篇**。

本探针把这一个点推广成一张图：**哪些领域在自己的方法学词汇里带对照，哪些不带。**

**为什么这值得测**：AI 驱动的假发现，最先出现在**没有对照纪律**的领域——
因为那里没有任何现成的东西会因为你造了个假发现而变红。

## 测量定义（写死）

对每个领域 F（由一个**多词短语**定义）与每个纪律词 T：

```
size(F)      = title_and_abstract.search:"F" 的命中数
hits(F,T)    = title_and_abstract.search:"F" AND title_and_abstract.search:"T" 的命中数
density(F,T) = hits(F,T) / size(F)
```

**只用多词短语。** 今天实测：单词加引号会匹配词干变体
（`"synthesizability"` 报 2,428,591 篇，首条是 *…molecular sieves **synthesized** by…*），
单词一律不可信。

## 仪器阳性对照（不过就整轮作废）

跑正式测量之前，仪器本身必须过这三关：

1. **`TI aspirin AND headache` ≥ 20 篇**，且首条确为阿司匹林治头痛 → AND 语义可用
2. **`"clinical trial"` ∩ `"positive control"` 的密度，必须显著高于全表中位数**
   —— 临床试验是对照纪律最强的领域，如果它不高，说明这个指标测的不是对照纪律
3. **`"pure mathematics"` 或同类形式学科的对照密度应接近 0**
   —— 数学不需要实验对照。如果它也高，说明指标在乱匹配

**第 2、3 条是双向的**：一个只会给高分或只会给低分的指标，分不出任何东西。

## 失败判据（整轮作废）

- 上述三关任一不过 → 退出码 2，读数不可用
- 任一领域 `size(F) < 500` → 该领域**单独标记为「口径过窄」**，不进排名
  （小分母会让密度剧烈抖动，那是噪声不是发现）
- API 失败率 > 15% → 读数不可用

## 明确不做的事

- **不解释因果。** 测到「某领域对照词密度低」只说明**它的报告规范里没有这个词**，
  不说明该领域研究者不做对照。这两句话差很远，混起来就是本项目一直在抓的那个病。
- **不给领域排优劣。** 数学不需要实验对照，密度低是对的，不是缺点。
- 不用单词检索。
- 不做全文检索（只有标题+摘要，OpenAlex 全文口径宽松到不可用）。

## 三态（承重点，与前四次同构）

```
measured    size ≥ 500 且 API 正常          → 进排名
too_narrow  size < 500                     → 单独列出，**不并入任何统计**
error       API 失败                        → 单独计数，**不并入任何统计**
```

把「我没测着」混进「它没有」，是本项目要抓的病。今天已经犯过一次，这里预先堵死。

## 诚实边界（必须与结论一起出现）

- 测的是**词汇出现率**，不是**实践发生率**。
- 领域由短语定义，口径换了数字就换。同一概念三种口径实测可差 3 万倍。
- 学科间术语习惯不同（物理可能说 "control experiment" 而不说 "positive control"），
  所以纪律词表必须**同时包含多个同义表达**，且逐词报数，不许只报总分。
