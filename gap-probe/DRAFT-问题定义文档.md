## 一、问题与证据

### 1.1 真实问题：一个人人在用、却从没人量过的推断

计算筛选新材料的标准流水线，最后一步几乎总是同一个动作：

> **把候选组分拿去比对实验数据库（ICSD / Materials Project / COD），
> 挑出「查不到条目」的，作为尚未合成的新材料候选。**

这一步把「**某个库里没有**」当作「**尚未被合成**」的证据。但数据库会滞后、会漏收、会因术语与写法不同而查不到；固溶体、非化学计量相根本不以化合物形式收录。

**这个推断的错误率是多少？我们检索后的答案是：没有人报告过。**

在披露的检索覆盖范围内（Crossref 15 条检索式 / arXiv 5 条 / Europe PMC 3 个短语 / 全文精读 24 篇），**37 篇使用该步骤的论文中，0 篇量化报告过它的假阴性率**。最接近的定量证据是 OQMD 自报的 ICSD 条目不完整率与 MC3D 的跨库失配率——**二者都不是这个数**。

于是我们自己去量。用 OpenAlex 检索确切措辞 `"absent from ICSD"`，得到**全网完整总体 5 篇**（7 条记录含两对预印本），全部开放获取，逐篇审计：

| 论文 | 被声称「不存在」的化合物 | 论文发表前已有已发表结构 | 是否声明该推断的局限 |
|---|---|---|---|
| npj Comput. Mater. 2024 | 19 | **6** | **是** |
| Energy Environ. Sci. 2021 | 3 | **1** | **否** |
| JACS 2024 | 13 | 0 | 是 |
| Crystals 2020 | 3 | 0 | 是 |
| npj Comput. Mater. 2023 | **0（不点名）** | — | 是 |
| **合计** | **38** | **7（18%）** | |

最长的一条：`Na₃HfF₇` 被 2024 年的论文列为「absent from the ICSD but predicted likely
synthesizable」，而 COD 条目 2310862 是 **1959 年 Acta Crystallographica**——**隔 65 年**。

**这不是指控作者。** COD ≠ ICSD，论文的字面陈述可能完全正确。我们量的是**那个推断**，不是那些人。

### 1.1b 最重要的一条：**声明局限并不能防止出错**

看上表最后一列。**5 篇里 4 篇明确声明了这条推断的局限**——而声明得最谨慎的那篇，
恰恰是错得最多的那篇：

> npj Comput. Mater. 2024 的原话是
> "The second category contains 50 materials which are not included in the ICSD database,
> indicating that **some of them** have not yet been synthesized."
> 用的是「其中一些」，不是全称；作者另外用 Scopus、Google Scholar 与两个文献指标核查过。
> **它仍然有 6/19（32%）的化合物在论文发表前就已被发表。**

一句「其中一些可能尚未合成」，不会让 `Na₃HfF₇` 那条 1959 年的结构出现在作者眼前。

> **披露不是控制。散文里的限定语挡不住任何东西——
> 只有一个会红的检查才挡得住。**

这正是本项目要论证的命题，而它此刻不是在我们自己身上成立，是在五篇公开发表、
作者审慎、同行评议过的论文上成立。

### 1.2 为什么它至今没有被结构化

三条独立佐证说明这个现象被反复撞见、却从未被当作研究对象：

1. **Crystals 2020** 自己记录：Rb₈Ga₈Sn₃₈ 与 Cs₈Ga₈Sn₃₈ 的结构 1998 年已报道，「然而 **ICSD 记录缺失**」。
2. **arXiv:1706.00192** 明写："…are not present in the ICSD-aflow.org repositories …
   **some of them are reported in other databases**" ——作者主动披露了局限。
3. **JACS 2024** 的作者**自查出 3 个目标在文献中已有**。

三次都是顺手记一句，**没有一次把它变成一个可测量的量**。原因不难理解：这个数对论文作者没有好处，跨学科、枯燥、且结论多半是负的。**它正好是自动化审计的射程，而不是人的射程。**

**必须一并披露的盲区**：Semantic Scholar 全部 429 限流、有效覆盖率≈0；Google Scholar / Bing 被反爬；无中文检索。**「0 篇」只在这个覆盖范围内成立，不等于不存在。**

### 1.3 研究价值与合适切片

**切片**：三元氧化物 + 「absent from ICSD」这一确切措辞的完整总体（5 篇，38 个化合物）。
不是抽样，是全体——因此可以给出率，而不只是举例。

**为什么值得**：AI for Science 正在大规模产出「发现」，而当模型既是发现者又是评判者时，**评测装置的失败模式与成功无法区分**。「数据库缺席 ⇒ 不存在」是这类自证结构里最普遍、最不设防的一个。给它装上可执行的对照，是给整条流水线装地基。

## 二、环境接口

### 2.1 固定部分（不可被 Agent 改动）

| 项 | 值 |
|---|---|
| 判定源 | COD `result.php?formula=<规范式>`，元素字母序、计数 1 省略 |
| 化学式解析 | 确定性函数，含括号展开，带 4/4 自检（`Ti(SO4)2` → `O8 S2 Ti`） |
| 纯度阈值 | θ = 0.995（由标定给出的**最严可用**值） |
| 阳性对照 | BaTiO₃ / LiCoO₂ / MgAl₂O₄ / SrTiO₃ / CaTiO₃ / ZnFe₂O₄，须非空且最早年份 < 2000 |
| 阴性对照 | 3 个编造化学式，须返回空 |
| 作废条件 | 对照任一不过；或「查询失败」比例 > 30% |
| 顺序约束 | 预注册文件的 sha256 必须先落盘、先进外部时间锚，**才允许发第一个查询**；代码强制校验，不符退出码 4 |

### 2.2 Agent 看到什么、能改什么、反馈从哪来

> **环境就是那五道闸门。**

- **动作**：提出一条规律，或一条「某化合物尚不存在」的主张
- **可探索**：规律的形式、特征的选择、阈值、检索式
- **反馈**（每次动作后立即返回）：
  - 阳性/阴性对照是否通过（不通过则本轮**不产出任何结论**）
  - 与**平凡解**的差值（平凡解 = 不做任何推理的常数预测）
  - McNemar 精确检验的 p 值
  - 覆盖率：查了多少、失败多少、**「失败」与「查到 0 条」分开计**
- **行动确实改变后续观察**：上一轮得到的规律直接决定下一轮查哪些格子。

**诚实声明：本轮 Agent 由人扮演。** 环境接口、闸门、反馈信号已全部形式化并可执行，
**自动化是下一步，不是已完成的部分。**

### 2.3 记录与预算

运行日志、查询缓存（可断点续跑）、预注册文件与其哈希、OpenTimestamps 时间锚全部落盘。
本轮预算：约 370 次数据库查询、约 6 小时。

## 三、发现信号与参照

### 3.1 什么算发现（开跑前定义，写死在文件里）

预注册文件 `PREREG-oos.json` 的 `successCriterion` 字段：

> **样本外 McNemar 双侧 p < 0.05 才算规律有预测力；否则判定为「与平凡解不可区分」。**

冻结顺序有外部背书：**预测冻结 → 进证据锚点清单 → 提交 OpenTimestamps（比特币时间戳）→ 才发第一个查询。**
门捷列夫的镓预测算数，是因为它写在镓被发现之前；一份没有外部时间锚的预注册，「之前」二字仍由自己签发。

### 3.2 平凡解 / 随机 / 无干预

**平凡解定义**：一个不做任何推理、永远给同一答案的常数预测器。

| | 平凡解 | 我们的规律 | 判决 |
|---|---|---|---|
| 样本内 116 格 | **77.6%** | 82.8% | McNemar p = 0.146　**不可区分** |
| 样本内（加入离子半径维度） | 77.6% | **77.6%** | **与平凡解逐位相同** |
| 样本外 63 格（预注册） | **73.0%** | 76.2% | McNemar p = 0.688　**不可区分** |

**最值得记住的一行**：那个「离子半径」维度，是为了解释四个反例（YIG、YAlO₃、SrZnO₂、BaZnO₂）才引入的；它确实解释了那四个，**而整体表现掉到平凡解以下**。

> **为异常修改规律，通常让规律变差。** 异常吸引注意力，而针对异常的精化多半是过拟合。

### 3.3 最低成功与失败标准

成功阈值写死在预注册里，**而且它真的把我们判死了**——两轮 McNemar 都判定「与平凡解不可区分」。
一条会红的判据，在自己身上响过，这比它没响过更能说明它是真的。

**因此本项目的主结论是负的**：我们没有得到任何一条能与平凡解区分开的规律，也没有得到可靠的「空格」。**而这正是要提交的东西。**

## 四、最小验证计划

### 4.1 一次试跑

```bash
node demo/gap-probe/probe2.mjs           # 对照前置 → 全表
node demo/gap-probe/law.mjs              # 平凡解对照 + McNemar
node demo/gap-probe/oos.mjs --prereg     # 冻结样本外预测（→ 盖时间章）
node demo/gap-probe/oos.mjs --run        # 校验哈希后才开查
node demo/gap-probe/audit-table2.mjs     # 已发表「不存在」主张的审计
node demo/gap-probe/verify-gap-probe.mjs # 判据；退出码 2 = 该轮作废
```

### 4.2 主要风险与失败路径

**两天里五次「我以为做出来了」，五次被下一道闸拦下。每一次结果都是全绿的。**

| # | 看起来的成果 | 拦下它的 | 该闸门此前存在吗 |
|---|---|---|---|
| 1 | 50 个「从未被实验观测的三元系」，286/286 查询成功、零失败 | 阳性对照：榜单第 3 名是**奥氏体不锈钢**，第 2 名是 Ti-6Al-4V；假空率 4/12 | 否，现造 |
| 2 | 判据「稠密邻域里的洞」是新方法 | 先行工作检索：Hautier & Ceder 2010 已做（`10.1021/cm100795d`） | 有，未执行 |
| 3 | 离子半径维度解释了异常 | **平凡解对照**：77.6% 对 77.6% | 否，现补 |
| 4 | AgGaSe₂（COD 1953）是战果 | 预注册的入选条件——**事前预防**，不是事后判死 | 是 |
| 5 | 「UP1」的首次结构主张被推翻 | 那是蛋白质结构域名，被抽取器读成 U+P，COD 返回 1941 年磷化铀 | 否 |

另有三次同型错误复发，均已固化为判据：检索失败冒充全称否定；把「查询失败」并入「对照未通过」；`catch{}` 静默吞异常。还有一条判据被 **CRLF 弄成空转**——正则 `.` 不匹配 `\r`，于是它从未检查过任何一行，**而它是绿的**。

> **「从没响过的守卫」与「坏掉的守卫」，从外面看没有区别。**

**第二个领域实例（优先权主张审计）当场失败**：仪器（无机晶体库）与总体（多为结构生物学）错配。此为负结果，如实提交。
