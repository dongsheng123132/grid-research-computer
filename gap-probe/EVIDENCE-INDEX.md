## 一、问题与证据

### 1.1 真实问题或需求

**核心数字（两个，都端到端可核）**

| 数字 | 含义 | 出处 |
|---|---|---|
| **0 / 37** | 使用「数据库无实验条目 → 候选新材料」这一步的论文中，**报告过该步骤假阴性率的篇数** | `litsearch-result.md`；45 个 DOI 全部经 Crossref 核实（`verify-lit.mjs`） |

### 1.2 为什么尚未被结构化

**不要写「据我所核」——那四个字没有覆盖率。** 用这两组：

- **检索覆盖表**：`litsearch-result.md` 的「检索覆盖」节。Crossref 15 式 / arXiv 5 式 /
  Europe PMC 3 短语 / 全文精读 24 篇。**必须连盲区一起写**：Semantic Scholar 全部 429 限流、
  有效覆盖率≈0；Google Scholar / Bing / OpenAlex（当时）被拦；无中文检索。
  **不写盲区就是我们自己在犯 N6。**
- **三条独立佐证**（不是我们说的，是论文自己说的）：
  1. `10.3390/cryst10040298`（Crystals 2020）：Rb₈Ga₈Sn₃₈ / Cs₈Ga₈Sn₃₈ 结构 1998 年已报道，
     而「**ICSD 记录缺失**」——一篇论文独立撞见并写下了我们在量的现象。
  2. `arXiv:1706.00192`：明写 "…are not present in the ICSD-aflow.org repositories …

**还缺的一格**（诚实写进去，或去补）：文献自报的 70% —— 「254 个已合成钙钛矿氧化物中
OQMD 只预测 186 个稳定」。这个数是从检索摘要里得到的二手转述，**我没回原文核过**，
引用前必须自己核，否则就是我们批的那个病。

### 1.3 研究价值与合适切片

## 二、环境接口

### 2.1 固定规则

| 固定项 | 值 | 出处 |
|---|---|---|
| 判定口径 | COD `result.php?formula=<规范式>`，元素字母序、计数 1 省略 | `audit.mjs` `normalize()`，带 4/4 自检（含括号展开 `Ti(SO4)2`） |
| 纯度阈值 | θ = 0.995 | `PREREG-oos.json`，由第二轮标定给出的**最严可用**阈值 |
| 阳性对照 | BaTiO₃ / LiCoO₂ / MgAl₂O₄ / SrTiO₃ / CaTiO₃ / ZnFe₂O₄ | `PREREG-audit.json` |
| 阴性对照 | 3 个编造化学式，必须返回空 | 同上 |
| 作废条件 | 对照任一不过；或 UNRESOLVED > 30% | 同上 |

### 2.2 观察 / 行动 / 反馈 ← **这一格是全篇最弱，必须重写而不是照抄**

模板要的是「Agent 在什么环境里行动、看到什么、能改变什么、如何获得反馈」。
**照现状写会被判成「这是分析脚本，不是探索环境」——而这一格占 45% 权重的一半。**

可成立的表述（这不是包装，是对已发生之事的准确描述）：

> **环境 = 那五道闸门。Agent 的动作 = 提出一条规律或一个「空格」主张。
> 反馈 = 判决红/绿 + 与平凡解的差值 + McNemar 的 p 值。**

- **固定部分**：数据源与查询口径、阳性/阴性对照集、平凡解的定义、
  「预注册必须先于查询」（由哈希校验强制，退出码 4）
- **可探索部分**：规律的形式、特征的选择、阈值
- **反馈**：每提一条规律，环境返回「比平凡解高几分」「p 是多少」「哪几个阳性对照红了」
- **发现信号**：一条经预注册后仍显著超过平凡解的规律

**必须诚实写明的一句**：本轮 agent 由人扮演，环境接口已定义，自动化是下一步。
藏这一句，就是我们整套东西在防的那个病。

模板自检清单问「Agent 的行动是否真的会改变后续观察和决策？」——**会**：
上一轮的规律直接决定了下一轮查哪 63 个格子（`PREREG-oos.json` → `cache-oos.json`）。

### 2.3 记录与预算

- 运行日志：`run2.log`、`run-oos.log`；缓存 `cache*.json`（可断点续跑）
- 预算：约 283 次 COD 查询（220 三元系 + 63 样本外），约 4 小时；审计另约 90 次

## 三、发现信号与参照 ← **全篇最强，往死里写**

### 3.1 什么算发现

**开跑前定义，写死在文件里**：`PREREG-oos.json` 的 `successCriterion` 字段——
「样本外 McNemar 双侧 p < 0.05 才算规律有预测力；否则判定：与平凡解不可区分」。

**冻结顺序有外部时间锚背书**：预测冻结 → 进锚点清单 → 提交 OpenTimestamps 日历 → **才发第一个查询**。
代码强制：`oos.mjs` phase B 开查前重算哈希，对不上退出码 4。

### 3.2 平凡解 / 随机 / 无干预 ← 这一格是全场最难被质疑的

| 轮次 | 平凡解「永远回答有」 | 我们的规律 | 判决 |
|---|---|---|---|
| 样本内 116 格 | **77.6%** | Δq≥1 得 82.8% | McNemar p=0.146 **不可区分** |
| 样本内 | 77.6% | 半径比≥1.1 得 **77.6%** | **与平凡解逐位相同** |
| 样本外 63 格（预注册） | **73.0%** | 76.2% | McNemar p=0.688 **不可区分** |

**最值得写进正文的一句**：我加的那个「离子半径」维度，是为了解释 YIG / YAlO₃ 四个反例才引入的；
它确实解释了那四个，**但整体表现掉到平凡解以下**。
→ **为异常修改规律，让规律变差。** 异常吸引注意力，而针对异常的精化通常就是过拟合。

### 3.3 最低成功与失败标准

写死在预注册里，**而且它真的把我们判死了**——这是最有说服力的部分：
一条会红的判据，在自己身上响过。

## 四、最小验证计划

### 4.1 一次试跑怎么做

```bash
node demo/gap-probe/probe2.mjs             # 对照前置：标定不过则一个格子都不产出
node demo/gap-probe/law.mjs                # 平凡解对照 + McNemar
node demo/gap-probe/oos.mjs --prereg       # 冻结样本外预测
node demo/gap-probe/oos.mjs --run          # 校验哈希后才开查
node demo/gap-probe/audit.mjs --run        # 已发表「不存在」主张的审计
node demo/gap-probe/verify-gap-probe.mjs   # 退出码 2 = 该轮作废
```

### 4.2 主要风险与失败路径 ← **第二强的一格，别谦虚**

**两天里五次「我以为做出来了」，五次被下一道闸拦下。每一次都全绿。**

| # | 我以为的成果 | 拦下它的 | 那道闸此前存在吗 |
|---|---|---|---|
| 1 | 50 个「从未被实验观测的三元系」，286/286 成功、零失败 | 阳性对照：榜单第 3 名是**奥氏体不锈钢**，第 2 名是 Ti-6Al-4V，假空率 4/12 | 否，现造 |
| 2 | 判据「稠密邻域里的洞」是新方法 | 先行工作检索：Hautier & Ceder 2010 做过（`doi:10.1021/cm100795d`） | 有，我没做 |
| 3 | 半径维度解释了异常 | **平凡解对照**：77.6% 对 77.6%，一分不差 | 否，现补 |
| 4 | AgGaSe₂（COD 1953）是战果 | 预注册的入选条件——**事前预防，不是事后判死** | 是 |
| 5 | 「UP1」首次结构主张被推翻 | 那是蛋白质结构域名，被抽取器读成 U+P，COD 返回 1941 年磷化铀 | 否，我的错 |

另有三次同型错误复发，都记在代码注释里：
检索失败冒充全称否定、把「查询失败」并进「对照没通过」、`catch {}` 静默吞异常。
还有一次判据被 **CRLF 弄成空转**——`.` 不匹配 `\r`，于是它从没检查过任何一行，
而它是绿的。**「从没响过的守卫」与「坏掉的守卫」，从外面看没有区别。**

**第二个领域实例（优先权主张审计）当场失败**，也要写：
仪器（COD，无机晶体库）与总体（多为结构生物学）错配——
与第一天把 COD 用在 Ti-6Al-4V 上是同一个范畴错误。
手册明写「负结果被明确允许」，这条是**最诚实的证据**，不是污点。
