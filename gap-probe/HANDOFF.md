## 1. 绝对不要做的事（违反即结论作废）

1. **不要在看过数据之后修改判定规则。**
   规则冻结在 `PREREG-*.json`，脚本开跑前会重算哈希，对不上退出码 4。
   若你改了规则，**必须新建一份 PREREG 并重新盖章**，不能改旧的。
   已盖章的锚点：`governance/anchors/71f45b565d9d49a3`、`33bbd90a0156ae98`。

2. **不要把「查询失败」并进「没查到」。**
   代码里 UNRESOLVED 是独立一类。这条被违反过三次，每次都产出了漂亮的假结论。

3. **不要审「论文没有声称它不存在」的化合物。**
   入选闸门在 `audit.mjs` 的 `ASSERTS_ABSENCE` 与 `audit4.mjs` 的 `OUT_OF_SCOPE`。
   历史教训：AgGaSe₂（COD 1953）、BN（1927）、BP（1957）都差点被当成战果——
   而论文只是把它们当**已知验证集**列的。**算术全对，结论是诬告。**

4. **不要把密钥写进任何源码或产出文件。**
   `.secrets/openalex.env`（已 gitignore）。`publish.mjs` 有 `secrets-dir` / `env-file` /
   `private-key` 三条路径规则 + `SECRET_PATTERNS` 内容扫描，但**内容扫描只覆盖 HEAD，不覆盖历史**。

5. **不要用 `git add -A`。** 多会话并发，会把别人的半成品一起提交。

## 3. 五个工具陷阱（全部实弹踩过，不是理论）

**3.1 COD ≠ ICSD ≠ 全部文献。**
COD 是**晶体结构**库，索引的是有确定化学计量的化合物。
它**不收固溶体合金**——Ti-6Al-4V 在任何阈值下都查不到，因为衍射上就报成「Ti」。
→ 拿 COD 问「这个合金系有没有人研究过」是**范畴错误**。氧化物这类定比相才是它的射程。

**3.2 COD 空响应是 `[  ]`（带空格），不是 `[]`。**
字符串等值比较会漏掉它。现在两条分支恰好都给 n=0，是**侥幸正确**，别依赖。

**3.3 OpenAlex 的引号短语检索只对独特短语有效。**
`"absent from the ICSD"` → 7 条，全对。
`"not in the ICSD"` → 24,731 条，里面有《International Classification of Sleep Disorders》——
**ICSD 是同名词，也指国际睡眠障碍分类。**
`"not been synthesized"` → 259,884 条，里面有 1959 年的《Tissue sulfhydryl groups》。
**常见词短语会静默退化成相关性排序，API 不给任何降级信号。**

**3.4 回摘要核实会把「核不了」误报成「没命中」。**
OpenAlex 检索的是**全文**，API 只吐**摘要**。短语在正文里时，回摘要核实必然 0%。
那 7 条核实率 0%，不是搜错了——**阳性对照就在里面（我们已审过的 npj 2024）**。
→ 摘要核实只能用于「加分」，不能用于「排除」。

**3.5 OpenAlex 免费额度按天共享，一轮 agent 检索就能烧光。**
现在有付费密钥，但**派活前仍应先探余额**（`openalex-sweep.mjs` 第一件事就是探）。

## 4. 第二个实例为什么失败，以及怎么救

**做了什么**：审计「the first crystal structure of X」这类优先权主张——
比「不在 ICSD 里」更硬，因为一条更早的**实验**报道即可直接推翻。
先行工作这次是**动手之前**核的：撤稿引用已被研究透（放弃），
而「first report of 主张被先前文献推翻的频率」检索明确报出空白（选它）。

**为什么失败**（`result-priority.json`）：
1. 该短语的总体**绝大多数是结构生物学**（蛋白质），而 COD 是无机晶体库 —— 又是 §3.1 的范畴错误。
2. 标题里的化学式抽取器把蛋白质结构域名 **UP1** 读成 U(铀)+P(磷)，
   COD 返回 1941 年磷化铀，被判成 PRIOR。
3. 200 条取回 → 回原文核实 74 → 标题中可抽出唯一化学式**仅 2 条**。子集太小。

**怎么救（下一轮该做的）**：
- 加学科过滤：OpenAlex 的 `primary_topic` / `concepts` 限定到无机化学/材料，剔除生物
- 或把蛋白质那半改用 **PDB**（`data.rcsb.org`，免费，已验证可用）
- 化学式抽取器加黑名单，并要求**至少两个真实元素符号且不构成常见英文缩写**
- **这是新的一轮，不是打补丁。** 规则要重新冻结重新盖章。
