# 空格探针 第一轮 · 结果作废报告

> 2026-08-11。一次会话内跑完。**结论是负的，而负结论是这一轮唯一可靠的产出。**

## 一句话

机器跑出了 50 个「从未被实验观测过的三元系」，其中包括**奥氏体不锈钢**和 **Ti-6Al-4V**。
286 次查询全部成功、零失败、每个格子的三条边都非空、探针自己的控制条条通过。
**从仪器内部看，这次失败与成功完全无法区分。**

## 做了什么

判据来自门捷列夫的真正逻辑——不是「这里是空的」，而是**「这里在满格的包围里是空的」**：

> 三元系在实验层为空 ∧ 它的三条二元边在实验层都非空

两层表、两个独立来源：

| 层 | 来源 | 免密钥 | 语义 |
|---|---|---|---|
| 实验观测 | [COD](https://www.crystallography.net/cod/) | 是 | `strictmin=N&strictmax=N` → 恰好 N 种元素的晶体结构 |
| 计算预测 | [AFLOW AFLUX](https://aflow.org/API/aflux/) | 是 | 高通量 DFT（本轮未用到，第一层就废了） |

调色板 12 元素（Fe Co Ni Mn Cr Ti V Al Cu Zn Mg Sn）→ 66 条二元边、220 个三元系。

## 结果

```
查询 286 次　成功 286　失败 0
三元系 220：已被实验观测 63　| 空但至少一条边也空（判据自己排除）107　| 查询失败 0　| ✦ 格子 50
```

排名前三的「格子」：`Fe-Ni-Sn`、`Fe-Cr-Ti`、**`Fe-Ni-Cr`**。

## 它为什么是错的

`Fe-Cr-Ni` 恰好三元 = **0 条**；同一系统超集口径 = **97 条、94 种化学式**——
全都多带了别的元素（P、Si、Mo、Cu、O、U…）。

**不是数据库没收，是操作化定义错了。** 真实的奥氏体不锈钢从来不是纯三元，它总带碳、锰、钼。
「恰好三种元素」这个可执行定义，与「这个三元系被研究过」不是一回事，而两者的差别
在探针内部没有任何投影。

阳性对照给出了这个错误的规模：**12 个以工业材料命名的三元系里，4 个被判成了格子（假空率 33%）。**

| 系统 | 判决 | 它其实是 |
|---|---|---|
| Fe-Cr-Ni | ❌ 判为格子 | 304/316 不锈钢的基体 |
| Ti-Al-V | ❌ 判为格子 | Ti-6Al-4V，航空钛合金用量第一 |
| Co-Cr-Al | ❌ 判为格子 | MCrAlY 热障涂层黏结层 |
| 其余 9 个 | ✔ 判为已观测 | — |

## 第二发致命伤：方法本身不新

即使第一层没废，这个判据也不是新的。检索到的先行工作：

- Hautier, Fischer, Jain, Mueller, Ceder, *Finding Nature's Missing Ternary Oxide Compounds
  Using Machine Learning and Density Functional Theory*, **Chem. Mater. 2010, 22(12), 3762–3767**,
  [doi:10.1021/cm100795d](https://pubs.acs.org/doi/10.1021/cm100795d) —— 同一逻辑，2010 年，
  一次算出 209 个新化合物。
- **PhaseSelect**（[arXiv:2202.01051](https://arxiv.org/pdf/2202.01051)）—— 对 87 元素的
  105,995 个三元组合排序，并用 ICSD-v2021 做独立验证。
- **矩阵/张量推荐系统**（[arXiv:1710.00659](https://arxiv.org/pdf/1710.00659)）—— 枚举
  7,405,200 个候选三元组分，其中仅 9,313 个已知（0.056%）。

**所以「稠密邻域里的洞」这个我提出的判据，本身就是一个幻觉出来的格子。**
它不是空的，它已经被填了十五年。

## 抓到它的是什么（这条最重要）

不是探针里的任何一条控制。是

1. 人认得「Fe-Ni-Cr 是不锈钢」——**领域知识，来自仪器外面**；
2. 一次针对**我自己方法**的文献检索。

探针自己的那条控制（要求三条边都非空）**失效了**：COD 里这些合金二元系的计数只有 3～14 条，
按「>0 即稠密」的阈值全部通过。绝对稀疏的表上，相对密度不构成对照。

## 补上的部件

`verify-gap-probe.mjs`，**空格判据 v0.1**。核心是一条此前不存在的对照：

> **平凡解对照防的是「预测其实没预测」；阳性对照防的是「空其实不空」。**
> 后者在本仓库、也在检索到的先行工作里，都没有任何部件在防。

当前判决 **13/16，退出码 2**——G1 的三个阳性对照红着，正确地宣布本轮作废。
判据集不由探针自己挑（那会是恒绿考题），入选理由一律是「有以它命名的工业材料」。

跑：
```bash
node demo/gap-probe/probe.mjs             # 带缓存，可断点续跑
node demo/gap-probe/verify-gap-probe.mjs  # 退出码 2 = 本轮作废
```

## 已知未覆盖（不藏）

- 只用了 COD 一个实验源。ICSD、Pauling File、MPDS 都是付费的，未查；OQMD 在本轮被限流挡住。
- AFLOW 那一层根本没跑到——第一层就废了，跑下去只是给错误的格子配上漂亮的形成焓。
- 调色板只有 12 个金属元素，且全部是常见元素；氧化物、氮化物、硫族化合物空间未触及。
- 「恰好 N 元素」之外的操作化定义（如「主元素 ≥ 95 at.%」）未实现，而那大概率才是对的口径。
- OpenAlex 已于本轮实测中改为按量计费（返回 `Insufficient budget`），文献层的免费全库检索路径当前不可用。

## 这一轮到底证明了什么

不是「AI 能发现新材料」。是：

**一台能自己发证的发现机器，会在全绿的状态下告诉你不锈钢从没被做出来过。**
所以「发现」的前置不是更强的模型，是**一条会因为「空其实不空」而变红的判据**——
而那条判据的输入，必须来自仪器外面。
