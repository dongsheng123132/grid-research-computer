```
Δq≥2 或 半径比≥1.2             78.4%   +0.9 分
```

**为异常修改规律，让规律变差。** 半径这个特征是为了解释 YIG、YAlO₃、SrZnO₂、BaZnO₂
四个反例才加进来的；它确实能解释那四个，但整体表现掉到平凡解以下。
异常吸引注意力，而针对异常的精化通常是过拟合——门捷列夫在 Te/I 上赌对了，那是例外不是通例。

## 筛子方向：一次跑出三类东西

「用格子去筛已有的东西」比「找空格」产出更丰富。同一遍扫描给出：

**一、规律太粗（我的错，不是数据的错）**
`Mn₂TiO₄` 里 Mn 是 +2 不是 +4，`MgCo₂O₄` 里 Co 是 +3 不是 +2。
上一版把多价元素定死成单一价态，于是**反例是我自己造的**。修法：枚举全部常见氧化态。

**二、记录本身有问题（「胖子」）**
```
Co₀.₁₅ZnO₀.₈₅   掺钴 ZnO 固溶体，被当成「Co-Zn-O 有三元化合物」
Ni₀.₉Zn₀.₁O     同上
Ca₂Co₀.₉₈₄O₂.₆₅₂ 非化学计量氧缺位相
```
它们不是格子空不空的问题，是**这几条记录不该进这一格**。

**三、真反例（规律该修）**
```
Y₃Fe₅O₁₂ (YIG)   Y³⁺ + Fe³⁺   同价却有序
YAlO₃            Y³⁺ + Al³⁺
SrZnO₂           Sr²⁺ + Zn²⁺
BaZnO₂           Ba²⁺ + Zn²⁺
```
这四个在最优规律 Δq≥1 下仍是残余（3 个：Sr-Zn-O、Ba-Zn-O、Al-Y-O）。
**这才是该交给化学家看的东西——不是 50 个空格，是 3 个异常。**

## 已知未覆盖

- 4 个格子查询超时未判定：`Na-Ca-O`、`Ca-Al-O`、`Ti-Fe-O`、`Fe-Al-O`（硅酸盐/尖晶石空间过大）。
- 二元边 16 条按教科书事实假定非空、未查询，故**邻域密度控制在氧化物表上是空转的**。
- 半径统一取 CN=6，实际配位数不同；A 位常为 12 配位，此简化会低估分化。
- 全部准确率均为**样本内**，且半径特征是看过异常之后才选的。干净的检验需要换一批阳离子做样本外，
  阈值先冻结、规则先写下——**已于 2026-08-11 补做，结论在下方「样本外」一节**。
- 只用了 COD 一个实验源。ICSD / Pauling File / MPDS 付费未查；OQMD 被限流。

## 样本外（预注册在先，2026-08-11 补做）

上面「尚未做」那条已经做了。**规则、阈值与新阳离子集合全部在任何查询之前冻结**，
预注册文件 `PREREG-oos.json`，指纹 `5669ffa37e96b95a7b4d96c719747d4538c20acdf615b947869268837ad33302`。

```
规则      dq>=1（存在一组常见氧化态指派使 |q_A − q_B| ≥ 1 → 预测存在有序三元相）
阈值      θ = 0.995（COD 中目标元素原子分数 ≥0.995 的不同化学式数 > 0）
新阳离子  K, Zr, Nb, La, Cd, Pb（旧集合按 result2.json 原顺序取前 8，未挑选）
格子      新×新 全部 + 新×旧8 全部 = 63
成功判据  样本外 McNemar 双侧 p < 0.05 才算规律有预测力
```

结果（`result-oos.json`、`run-oos.log`）：

| | 准确率 |
|---|---|
| 规律 dq≥1 | 76.19 %（48/63） |
| 平凡解「永远回答有」 | 73.02 %（46/63） |
| McNemar | b=2, c=4，双侧 **p = 0.6875** |

**判定：该规律在样本外与平凡解不可区分。** 与样本内那一轮（82.8 %，p=0.146）结论一致，
