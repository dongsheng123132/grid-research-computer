# 基因符号假空探针 · 预注册（接触数据之前写死）

> 2026-08-12。第七份。今天已有两次预注册闸门救下错误结论，不改顺序。

## 要测什么

生物信息流水线里一条极常见的判据：
**「这个基因符号在参考库里（按官方符号精确匹配）查不到 → 判为未知基因 / 注释缺失 / 新发现」**

与前三个学科逐条同构：

| | 朴素判据 | 击穿者 |
|---|---|---|
| 材料 | 库里**恰好**含这 3 种元素 = 0 → 从未合成 | Fe-Cr-Ni（不锈钢基体） |
| 天文 | 库里**恰好**这个名字 = 0 → 未编目 | Crab Nebula → 主名 "M 1" |
| **基因** | **库里恰好这个符号 = 0 → 未知基因** | **见对照集** |

预探已见三例：`MLL`（→KMT2A，最著名癌基因之一）、`SEPT2`（→SEPTIN2，
**改名原因是 Excel 会把它自动纠正成日期**）、`CD11B`（→ITGAM，标准免疫标记）——
朴素精确查询三个全部查不到。

## 阳性对照（标准写死，条目由外部生成后人工核准）

= **教科书级、在数千篇既有文献里被使用过的旧符号**。
朴素判据若把它判为「未知基因」即为击穿。选取标准：
1. 该基因本身是教科书级（癌基因、标准标记、经典通路成员）
2. 旧符号在文献中被广泛使用过
3. 官方符号已变更或旧符号仅作为别名存在

## 三态判决（承重点，与前三次同构）

```
exact_hit    symbol:X 精确查到，且官方符号 == X        → 朴素判据说「已知」✓
alias_only   symbol:X 查不到，但通用查询 q=X 能解析到  → **朴素判据说「未知基因」= 假空**
unresolved   两种查询都查不到                          → **单独计数，绝不并入假空**
error        接口失败                                  → 单独计数，绝不并入任何结论
```

假空率分母 = exact_hit + alias_only。**unresolved 与 error 不进分母**（sky-probe 教训）。

## 反向判据

- **R1** 至少一条 `exact_hit`，否则探针可能对任何输入都报「查不到」
- **R2** 注入一个**故意编造的符号**（`ZZQX9`），必须落进 `unresolved`，**不得被写成「新基因」**
- **R3** `TP53` 必须 `exact_hit`。若连它都查不到，检索口径坏了，**整轮作废**

## 失败判据

- R1 或 R3 不成立 → 退出码 2，整轮作废
- error 占比 > 20% → 读数不可用

## 明确不做的事

- 不评价基因命名委员会。符号变更有正当理由（Excel 问题就是其一）。
  **被测的是「流水线怎么处理变更」，不是「该不该变更」。**
- 不做同义词展开——**不展开正是被测的那个缺陷本身**。
- 不声称这些基因「未被注释」。**测的是朴素判据会怎么判，不是世界怎么样。**
