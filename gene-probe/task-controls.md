# 任务：生成「已改名/旧符号」基因对照清单

## 背景
生信流水线常用一条判据：「基因符号在库里按官方符号精确查不到 → 判为未知基因」。
我要测它的假阳性率：拿一批**教科书级、且旧符号在数千篇文献里被用过**的基因，
看这条判据会把多少个判成「未知」。

## 你要产出什么
JSON 数组，40 条：

```json
{"old": "MLL", "new": "KMT2A", "why_famous": "混合谱系白血病基因，儿童白血病最重要的易位伙伴之一，教科书必讲", "why_renamed": "HGNC 统一为组蛋白甲基转移酶 KMT 家族命名"}
```

## 三条硬标准
1. **教科书级**：癌基因/抑癌基因、标准细胞表面标记（CD 系列）、经典通路成员、或常见疾病基因
2. **旧符号被广泛使用过**：在 PubMed 上应有大量论文用旧符号
3. `old` 与 `new` 必须**不同**，且都用英文标准写法（会被直接拿去查 mygene.info）

## 建议覆盖（分散，别全是癌基因）
- 癌基因/抑癌基因 ≥ 10（如 MLL→KMT2A）
- CD 系列表面标记 ≥ 8（如 CD11B→ITGAM）
- SEPT 家族（Excel 自动纠正导致的改名）≥ 4
- 经典通路/信号分子 ≥ 8
- 其他（受体、转运体、代谢酶、线粒体基因）≥ 10

## 禁止
- **不许编造**。拿不准宁可不写。我会用 mygene.info 逐条核实，编造会被当场查出。
- 只输出 JSON 数组，不要解释文字。
