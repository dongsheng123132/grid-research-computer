# 论文方言 v0.0 —— 字段由实测推出，不由设想推出

> 2026-08-11 深夜。**这份 schema 只写现在能证明必要的字段。**
> 本仓库给「先设计好再去用」的 schema 起过名：**「一份没人加载的 schema」**——
> 它让人以为格式被约束着，而现实里没有。今天给 fact 加生命周期字段之前，
> 先量了 445 条事实、量了「按时间算有 204 条假过期」，字段才落下来。这里照同一条规矩。

## 已经证明必要的字段（每条都指向一次实测）

| 字段 | 为什么必要（证据） |
|---|---|
| `terminology_variants[]` | LBD 冒烟：8 对教科书药物×疾病**全部共现，假空率 0%**。说明真正的失败不在「关系冷门」，而在**术语写法**。`vitamin C` 查得到，`ascorbic acid` 未必是同一个检索结果 |
| `literature_domain` | 同上：40 条对照全在生物医学**内部**，所以必然共现。而 ABC 模型是在**互不相通的文献之间**工作的。不记「这条主张活在哪个文献圈」，就测不出 Swanson 的真实场景 |
| `cooccurrence_evidence{query, source, hit_count, synonym_expansion}` | 「查不到」必须可复核。Europe PMC 默认 `synonym=false`——**这个开关会翻转结论**，不记下来结果不可解释（同 prospector 那次：预算参数翻转了「有矿/已淘尽」） |
| `entity_resolved` | 三态承重点：`Zorbaxine × Kleptophagia` 被正确判为 `unresolved` 而非「重大新发现」。「实体查不着」与「关系没被说过」必须是两个字段，不是一个布尔 |
| `verification_status` | 沿用学籍 fact/0.1：`active / stale / superseded / refuted`。论文对象同样只涨不降就会腐烂 |

## 明确**不写**的字段（等有证据再加）

- `claim` 的细粒度结构（主张/证据/方法三元组）—— 还没有任何一次实测需要它。
  先写会变成第二份没人加载的 schema。
- 向量嵌入 —— 目前所有判据都是精确检索，没有一条需要相似度。
- 引用关系图 —— OpenCitations 能给，但**还没有哪个判据会因为它缺失而变红**。
  按命名裁决 §5：没有判据会因某字段缺失而变红时，那个字段只能是 candidate。

## 下一步要先做的实测（决定下一批字段）

**换一批「难的」阳性对照**：跨文献圈、术语不匹配的已知关系。
只有在那批上测出非零假空率，才谈得上给方言加同义词归一与跨域链接字段。

现在这批对照的正确用途是**下限**：它证明了在最容易的情形下 ABC 判据不出错——
**这本身是个有用的负结果，它把「LBD 到处是假空」这个我原本的假设否掉了。**
