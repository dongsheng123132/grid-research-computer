## 要测什么

文献连接发现（Literature-Based Discovery, Swanson 1986）的 ABC 模型判据是：

```
A-B 在文献里有、B-C 在文献里有、**A-C 查不到** → 判定 A-C 是「未被发现的连接」
```

四十年来它出过真金（鱼油↔雷诺氏综合征，后被临床证实；镁↔偏头痛；吲哚美辛↔阿尔茨海默），
**但没有任何一篇量化过这一步的假阳性率**——即「A-C 查不到」里有多少其实早就被人说过。

本探针只测这一件事，**不做假设生成**。

## 阳性对照（在跑之前定死，跑完不许增删）

阳性对照 = **教科书级、众所周知、早已确立的 A–C 关系**。
朴素 ABC 判据若把其中任何一条判为「未被发现的连接」，即为击穿。

选取标准（先写死）：
1. 关系在任何一本入门教材里都有
2. 关系确立时间早于 2000 年
3. **A 与 C 必须是不同类别的实体**（药物/物质 ↔ 疾病/症状），与 ABC 模型的典型用法一致

具体条目由外部生成（见「分工」），**但必须逐条满足上述三条，且由我人工核准后才冻结**。

## 三态判决（承重点，与前三次同构）

对每一对 (A, C)：

```
co_occurs        库中检索到 A 与 C 共现的文献 ≥1 篇  → 朴素判据说「已知连接」✓
no_co_occurrence 检索到 0 篇                        → **朴素判据说「未被发现的连接」= 假空**
unresolved       A 或 C 本身在库中检索不到          → **单独计数，绝不并入假空**
error            网络/接口失败                       → 单独计数，绝不并入任何结论
```

**最后两档必须单独出数。** 把「我没查着」混进「世界上没有」，正是本项目要抓的病；
混进去就等于自己复发一次（sky-probe 里已经写过一遍，这里不许再犯）。

## 假空率的分母（防装饰数字）

```
分母 = co_occurs + no_co_occurrence          ← 只含成功解析的
分子 = no_co_occurrence
```

**unresolved 与 error 不进分母。** 理由同 sky-probe：用「我没查着」去撑「流水线会误判」，
比率就是装饰。sky-probe 那轮我差点把一个 96.7% 的装饰数字当结论交出去，这里预先堵死。

## 检索口径（必须写死，否则「查不到」不可解释）

- 检索源：Semantic Scholar Academic Graph（主）
- 查询式：`"<A>" "<C>"`（两词均加引号，同时出现）
- 检索字段：**标题 + 摘要**（这是 ABC 模型的常见实现口径，也是被测对象）
- 每对最多取 3 条结果即可判定共现
- **同义词一律不展开** —— 因为「不展开同义词」正是被测的那个缺陷本身。
  展开了就不是在测朴素判据了，那是在测一个更好的判据。

## 反向判据（探针自己不许恒绿也不许恒红）

- **R1** 必须存在至少一对判为 `co_occurs` ——否则探针可能对任何输入都报「查不到」，等于没测
- **R2** 注入一对**故意编造的实体**（如 `"Zorbaxine"` × `"Kleptophagia"`），
  必须落进 `unresolved` 或 `no_co_occurrence`，**且不得被写成「重大新发现」**
- **R3** Swanson 的鱼油↔雷诺氏在**今天**必须判为 `co_occurs`（1986 年后已被大量研究），
  若判为「未被发现」，说明检索口径坏了，**整轮作废**

## 失败判据（整轮作废的条件）

- `error` 占比 > 20% → 网络不可靠，本轮读数不可用
- R1 或 R3 不成立 → 检索口径坏了，本轮作废，退出码 2
- 阳性对照条目未经人工核准 → 不许开跑
