# 任务：生成「文献连接」阳性对照清单

## 背景（读懂再动手）
文献连接发现（LBD）的 ABC 模型有一条判据：
「A 和 C 在文献里查不到共现 → 判定 A-C 是一个尚未被发现的连接」。

我要测这条判据的**假阳性率**：拿一批**众所周知、早已确立**的 A-C 关系去查，
看这条判据会把多少个判成「未被发现的新连接」。

所以我需要的是：**关系确凿到不可能是新发现的 A-C 对。**

## 你要产出什么

JSON 数组，40 条，每条形如：

```json
{
  "a": "aspirin",
  "c": "headache",
  "relation": "aspirin relieves headache",
  "why_textbook": "解热镇痛的教科书首例；1899 年拜耳上市，任何药理学入门教材第一章",
  "established_before": 1900
}
```

## 三条硬标准（每条都必须满足，逐条自查）

1. **教科书级**：任何一本相关学科的入门教材里都有这条关系
2. **确立时间早于 2000 年**（`established_before` 必须填一个具体年份）
3. **A 与 C 必须是不同类别的实体**：A = 药物/物质/营养素，C = 疾病/症状/生理状态
   （不要写「阿司匹林 ↔ 水杨酸」这种同类别的）

## 术语要求（很重要）
- `a` 和 `c` 一律用**英文学术检索里最常用的写法**（会被直接拿去查 Semantic Scholar）
- 不要用缩写，除非缩写本身就是标准检索词
- 不要写中文

## 覆盖要求
分散在不同领域，别全是止痛药：
- 药物 ↔ 疾病 ≥ 12
- 营养素/维生素 ↔ 缺乏症 ≥ 8
- 激素/内源物质 ↔ 生理状态 ≥ 6
- 毒物/致病因子 ↔ 疾病 ≥ 6
- 其他（微生物、元素、饮食因子）≥ 8

## 禁止
- **不许编造**。拿不准的宁可不写。我会用 Semantic Scholar 逐对核实。
- 不要写任何解释性文字，只输出 JSON 数组本身。
- **不要写 Swanson 那三条**（鱼油-雷诺氏综合征、镁-偏头痛、吲哚美辛-阿尔茨海默）——
  那三条我另有用途，混进来会污染对照集。
