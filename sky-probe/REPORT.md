# 天文假空探针 —— 闸门跨学科复现

> 2026-08-11｜目的不是「多做一个领域」，是回答一个具体质疑：
> **那五道闸门是不是只对材料有效？** 一个案例撑不起「范式」两个字。

## 结论

**同一套闸门，换一个学科，当场击穿，退出码相同。**

```
node demo/gap-probe/verify-gap-probe.mjs   → 退出码 2（材料：Fe-Cr-Ni 等 3/12 阳性对照被判为空）
node demo/sky-probe/verify-sky-probe.mjs   → 退出码 2（天文：8/8 教科书天体被判为未编目）
```

被复刻的是**同一个操作化错误**，不是同一段代码：

| | 材料（gap-probe） | 天文（sky-probe） |
|---|---|---|
| 朴素判据 | 「**恰好**含这 3 种元素」的条目数 = 0 → 从未被合成 | 「**恰好**这个名字」的条目数 = 0 → 未编目 / 新发现候选 |
| 击穿者 | Fe-Cr-Ni（304/316 不锈钢基体） | Crab Nebula、Andromeda Galaxy、Pleiades… |
| 错因 | 不锈钢以多组分固溶体存在，永不「恰好三元」 | 同一天体有 N 个名字，你手里那个未必是主名 |
| 共同点 | **把检索口径当成了世界。代码没错，定义错了。** | |

## 第六次「看起来成功」——这次是我自己

**探针第一版报出「假空率 96.7%」，我差点把它当成结论写出去。它是个装饰数字。**

样本按构造全部取自**别名**，「别名与主名不同」几乎是同义反复。分母是我自己造出来的，
这个比率不度量任何东西。**材料那一轮的五次假成功，在这里出现了第六次，形状一模一样：
一个漂亮的、内部一致的、可以直接写进 slide 的数字。**

保留这个数字并注明它的条件，比删掉它更诚实——但**它不能当结论**。真正站得住的是下面两条。

## 两条真发现（都不是比率）

### ① 主名规则不一致，方向相反 —— 所以失败不可预测

```
M 44      → 主名 NGC 2632      （Messier 编号不是主名）
NGC 7078  → 主名 M 15          （Messier 编号才是主名）
```

同一个库、同一类天体、两个方向。**这意味着「按主名精确匹配」的流水线，其失败没有可依赖的规律**——
你无法通过「记住 Messier 优先」之类的经验来规避。已锁成判据 S4.1。

### ② 权威库自己也有假空

SIMBAD **完全不索引 Caldwell 编号**：`C 63` / `Caldwell 63` / `C 77` / `C 169` 全部查不到，
而同一天体的 `NGC 7293` 查得到。Caldwell 是 Patrick Moore 的真实目录，被广泛使用。

更刺眼的一对：

```
"Beehive Cluster"  → 库里没有
"Praesepe"         → NGC 2632     （同一个天体，同样是真实通用名）
```

**所以「查不到」有三种成因，而朴素流水线会把它们写成同一句话**：
①口径不对（主名不同）②库有覆盖缺口（Caldwell）③名字是编的。
这与 gap-probe 的 `UNKNOWN / FAILED / NEGATIVE` 必须三态分开，是同一条不变量在另一个学科的复现。

## 粗筛外包、判断不外包的一次实证

40 条对照清单由本机 Hermes 生成（bulk 召回），**由 SIMBAD 逐条核验**（判断）。

- Hermes 自己划清了边界：交付时明写「别名真实性待 SIMBAD 核验，此前不应宣称已核实」。
- 96 个别名里**抓出 1 个编造**：`C 169`——Caldwell 目录只到 C109，且明确排除 Messier 天体，
  所以 M 15 不可能有 Caldwell 编号。它被判入 `unresolved` 而**没有**被写成「未编目的新天体」，
  这一条已锁成反向判据 S3.2。

**一个幻觉进来，被下游的权威源当场杀死，且没有污染结论。** 这正是分工要达到的效果。

## 已知未覆盖

- 只用了 SIMBAD 一个交叉证认源；VizieR / NED / TNS 未查。**与材料那轮只用 COD 是同一种限制。**
- 对照集由语言模型生成后人工+API 核验，不是随机抽样，**假空率不能外推**。
- 「按名字精确匹配」是朴素流水线的一种；坐标交叉证认 + 过小匹配半径是另一种同型错误，本轮未做。
