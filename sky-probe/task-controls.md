# 任务：生成天文「阳性对照」候选清单

## 背景（读懂再动手）
我要做一个反向测试：证明「按名字在目录里查不到 → 判定为未编目的新天体」这个朴素判据会出错。
做法是拿一批**教科书级、绝不可能是新发现**的天体，用它们**在文献里真实通用的名字**去查权威库，
看朴素判据会把多少个判成「未编目」。

所以我需要的是：**著名到不可能被判为新发现的天体，加上它们的常用别名。**

## 你要产出什么

一个 JSON 数组，40 条，每条形如：

```json
{"canonical": "M 1", "why_famous": "蟹状星云，1054 年超新星遗迹，教科书必讲", "aliases": ["Crab Nebula", "NGC 1952", "Taurus A", "3C 144"]}
```

字段要求：
- `canonical`：你认为的 SIMBAD 主名写法（不确定就写最常见的那个，我会去核）
- `why_famous`：一句话，为什么它绝不可能是「新发现」。要具体（教科书章节、历史事件、命名由来），不要写「很有名」
- `aliases`：**2~5 个在真实文献里被使用过的别名**，包括不同目录编号（NGC/IC/HD/HR/Messier）、俗名、射电源名等

## 覆盖要求（重要）
40 条要分散在不同类型，别全是星云：
- 恒星（含变星、双星）≥ 10
- 星云 / 超新星遗迹 ≥ 8
- 星系 / 星系团 ≥ 8
- 星团 ≥ 5
- 其他（脉冲星、类星体、X 射线源、系外行星宿主星）≥ 5

## 禁止
- **不许编造别名**。拿不准的别名宁可不写，也不要猜一个像模像样的编号。
  我会用 SIMBAD API 逐条核验，编造会被当场查出来。
- 不要写解释性文字，只输出 JSON 数组本身。
