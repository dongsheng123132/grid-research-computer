# 口径敏感度 · 随机抽样 n=1000 —— 本轮报告

> 2026-08-24。规则见 [PREREG-v2.md](PREREG-v2.md)（抽样之前写死，已进外部时间锚）；
> v1 普查版 [PREREG.md](PREREG.md) 保留为 superseded，一个字节未改。
> 判据 [verify-trend-scale.mjs](verify-trend-scale.mjs) 与预注册同批落盘，**写在数据之前**。
> 复现：`node scale.mjs`（3000 次 OpenAlex 请求，约 55 分钟）→ `node verify-trend-scale.mjs`（退出码须为 0）。

## 0. 这一轮回答的是哪个质问

trend-probe v0.1 报过一个数：同一概念 "literature-based discovery" 在 OpenAlex 上，
三种检索口径命中 1,815,368 / 775 / 223 —— 差约 8000 倍。

那是 **n=7 的轶事**。任何评委都可以问：**你是不是挑了七个最夸张的短语？**

本轮的回答方式是不自己拟词表：抽样框用 OpenAlex 自己维护的全部 4516 个 topic，
按写死的种子随机抽 1000 个。**词表由谁拟，结论就归谁**——这个框我们控制不了。

## 1. 判决

```
判决 30/30　退出码 0
```

三种篡改注入全部变红（这一节是本报告里唯一能证明上面那行不是恒绿的东西）：

| 注入 | 变红的判据 |
| --- | --- |
| 把中位数抬高 50% | S5.1（统计量逐条复算） |
| 把一条 `title_phrase=0` 的行洗成 `measured` | S2.1 + S2.3（三态复分类） |
| 删掉 734 条碍事的 `too_narrow` 让数据好看 | S1.2 + S1.5 + S2.4 + S7.3 |

**S1.5 是本轮的承重条**：判据拿预注册写死的种子**自己独立重抽一遍**，与 `rows` 逐条比对。
采数者报的样本不算数——否则「随机抽样」四个字由采数者自己签发。

## 2. 结果

| | 条数 | 占比（95% CI，带 FPC） |
| --- | ---: | --- |
| `measured`（标题短语命中 ≥10） | 266 | 26.6% |
| `too_narrow`（命中 <10，其中 **456 条为 0**） | 734 | **73.4%**　[70.9, 75.7] |
| `error` | 0 | 0% |

在 266 个 measured 上：

| 量 | 值 |
| --- | ---: |
| ratio 中位数（全文宽松 ÷ 标题短语） | **11,364** |
| P5 / P95 | 212 / 191,314 |
| ratio ≥ 1000 的占比 | **85.7%**　[81.5, 88.9] |
| ratio < 100 的占比 | 1.9%　[1.0, 4.2] |

**「差几千倍」不是个例，是常态**：266 个里 228 个（85.7%）差三个数量级以上。
n=7 那个 8000 倍的轶事，落在这个样本的中位数附近。

## 3. 倍数不是常数，它随概念变化 —— 这是本轮真正的新东西

| 倍数最大 | 全文 / 标题+摘要 / 标题 |
| --- | --- |
| Health and Education Studies　464,517× | 5,574,205 / 61 / 12 |
| Complex Network Analysis Techniques　341,248× | 3,412,480 / 52 / 10 |
| Data Quality and Management　331,436× | 7,623,025 / 201 / 23 |

| 倍数最小 | 全文 / 标题+摘要 / 标题 |
| --- | --- |
| Coronary Artery Anomalies　51.7× | 50,705 / 2,842 / 981 |
| Macrophage Migration Inhibitory Factor　53.1× | 194,126 / 6,843 / 3,656 |
| Vehicular Ad Hoc Networks (VANETs)　57.0× | 29,251 / 13,055 / 513 |

**跨度约 9000 倍（52× ~ 464,517×）。** 两端的形状是分开的：倍数最大的都是由常用词拼成的
宽泛标签（"Health and Education Studies"），它的每个词在全文里到处都是、整串却极少出现在标题里；
倍数最小的都是术语特异的专名。

**这条比「差 8000 倍」更难反驳，也更有用**：如果倍数是个常数，报一个数再乘个系数就行了；
**它不是常数，所以任何单口径的文献量曲线，其偏差量本身是未知的**——除非你把口径写清楚。

⚠ 上面这段只是对观察到的分布的**描述**。「宽泛标签 vs 术语特异」是我们看着两端总结的，
**没有预注册、没有独立测量**，因此它是待检验的假设，不是本轮的结论。

## 4. 我们自己的两条预测被自己的数据推翻

四条预测逐字写在 v1 里（数据之前），v2 一个字没改。判据 S6.1 强制四条结局**逐条落盘**，
不许只报成立的那两条。

| | 预测 | 实测 | |
| --- | --- | --- | --- |
| P1 | ratio 中位数 ≥ 100 | 11,364 | ✅ 成立 |
| P2 | ratio ≥ 1000 占比 ≥ 10% | 85.7% | ✅ 成立 |
| P3 | P95/P5 ≥ 10⁴ | **901** | ❌ **被推翻** |
| P4 | too_narrow 占比 < 30% | **73.4%** | ❌ **被推翻** |

**P3 被推翻**说明我们高估了分布的离散程度：倍数确实跨了约 3 个数量级，不是 4 个。
**P2 成立、P3 不成立**并不矛盾——前者说的是「多数概念差得很多」，后者说的是「差多少的跨度」，
我们把后者猜大了。

**P4 被推翻是本轮最重要的一条，而它是一条坏消息。** 见下节。

## 5. P4 被推翻意味着什么：一个必须与结论同页的外部效度限制

1000 个 topic 里 **734 个（73.4%）的标题短语命中不足 10 篇，其中 456 个是 0 篇**。

也就是说：**OpenAlex 的 `display_name` 多数不是研究者真会输入的检索式。**
"Military Technology and Strategies" 是 OpenAlex 编的分类标签，没人拿它当关键词检索。

这直接限制了第 2、3 节的外部推广力：

- 第 2、3 节的数字**只对那 266 个「作为检索式还站得住」的 topic 成立**，
  不能读成「OpenAlex 上任意概念的口径差中位数是 11,364」。
- 734 条**没有被删，也没有被折算成任何数字**。它们以 `too_narrow` 的身份留在 `rows` 里，
  条数与 measured 一起报。**把「我没测着」混进「它没有」，正是这台仪器要拦的那件事**——
  在自己的报告里也一样拦。

**这条限制我们事先没料到**（所以才写成 P4 并被推翻）。但预注册的价值恰在这里：
如果不是事先写死了「too_narrow < 30%」这条会输的预测，
今天完全可以只报「266 个概念的中位倍数 11,364」，读的人无从知道分母被扔掉了 73%。

## 6. 本轮明确没做的事

- **不解释因果。** 测到某 topic 口径差大，只说明这个词串在全文里比在标题里常见得多，
  不说明该领域的文献量被高估了。
- **不给 topic 排优劣。** 倍数大不是缺点，是「这个词需要注明口径」。
- **不做跨时间比较。** 本轮是一个时间点的截面，OpenAlex 索引天天在长。
- **不给分位数配区间。** 分位数的区间需要额外分布假设，本轮不做；给了就是无依据的精确感。
- **第 3 节的「宽泛标签 vs 术语特异」不是结论**，是看着数据总结的待检假设（见该节末尾）。

## 7. 诚实边界

- 这是 4516 中抽 1000（22.1%）的**随机样本，不是普查**。所有比例都带抽样误差，
  区间已用带有限总体校正（FPC=0.8825）的 Wilson 法给出，点估计不得脱离区间单独引用。
- 测的是 **OpenAlex 一家的检索行为**，不是文献计量学普遍如此。换 Scopus/WoS 结论可能不同。
- 全文口径（`search=`）宽松到何种程度没有公开文档，本轮只测其**后果**（命中数差多少），
  不主张知道其**机制**。
- **降级为抽样的原因是预算，不是数据。** OpenAlex 自 2026-08-24 实测已按额度计费
  （匿名档 $0.10/天 = 100 次；每请求 10 credits = $0.001），全总体 13,548 次需 $13.55。
  判断标准与四条预测与普查版逐字相同，两份预注册都在盘上，可直接 diff 出改了什么。
- **写 v2 之前已看过一次 20 条的冒烟结果**（`too_narrow 17/20`）。因此 v2 未新增任何预测——
  看过数据之后补的预测不是预测。这条污染写在 PREREG-v2.md 里，不是事后补的。
