# 口径敏感度 · 重抽样 v2（换语料时间切片）—— 预注册

> 2026-09-02。本文件写在数据之前。
> 这是对原实验（`trend-probe/scale/`）的稳健性检验：
> **不换随机种子重跑同一批数据，而是换一个不同的语料时间切片 + 换一批 topic。**

## 为什么这样改（对照逻辑）

原实验（v2, n=1000, seed=`trend-scale-v2-20260824`）查的是 OpenAlex **全历史**索引。
三个独立评审一致指出：只跑一次、一个种子，不能证明"11364 倍中位数"是稳健的。

本轮对照设计回答一个具体问题：
**如果把检索范围从「全历史」收窄到「近十年（2015–2024）」，
口径倍数结构是否还保持原样？**

- 如果倍数结构基本不变 → 说明原发现与历史深度无关，现象本身是稳健的
- 如果倍数大幅收缩 → 说明原发现部分依赖于 OpenAlex 历史索引的累积效应（越老的库越容易在全文命中但不在标题命中），外部效度需重新评估

外加换种子（不同的一批 topic），同时检验抽样稳健性。

## 和原方法的差异（逐条列出）

| 维度 | 原实验 (v2) | 本轮重抽样 |
| --- | --- | --- |
| API 查询 | `works?search=<phrase>` 等，无年份限制 | 三口径各加 `filter=publication_year:2015-2024` |
| 抽样框 | `topics.json`（4516 个 topic） | 同一个 `topics.json`，不变 |
| 种子 | `trend-scale-v2-20260824` | `trend-scale-resample2-20260902` |
| n | 1000 | **500**（受 API 额度约束，但 500 足够统计推断） |
| 测量/三态/分类 | 同原方法，逐字沿用 | **逐字沿用**，不重定义 |

## 抽样框与抽样方法（写死）

- **抽样框** = 复用同目录上级 `topics.json`，sha256 不变：
  `7df1bf6f2a819bbbc9c22483894188e61384bcb69b63f6ce8802a2b29b2b15c9`
- **样本量 n = 500**（1500 次 API 请求，在现有额度内）
- **种子 = `trend-scale-resample2-20260902`**（本文件写死）
- **抽法**：和原实验完全相同的确定性 PRNG（xmur3 + mulberry32 Fisher–Yates）
  对 topics 按 id 字典序排序后洗牌，取前 500 个。

## 预测：写死在数据之前

本轮预测分两层——
**复制预测**（P1/P2，和原实验逐字相同，用于检验现象本身是否复现）：
**稳健预测**（P3/P4，针对"换了时间切片后是否还一样"的新问题）：

```
P1  measured 的 ratio 中位数 ≥ 100（复制原实验 P1）
P2  measured 中 ratio ≥ 1000 的占比 ≥ 10%（复制原实验 P2）
P3  本轮 ratio 中位数在原实验的 0.5× 到 2.0× 之间，
    即落在 [5682, 22728] 区间内（判断"倍数结构是否剧烈漂移"）
P4  too_narrow 占比在 50%–85% 之间（判断"topic 作为检索式站不住的比例"是否稳定）
```

P1/P2 如果有一项不成立 → 原发现对语料时间切片敏感。
P3 如果不成立（中位数跑了 2 倍以上）→ 倍数结构的量级本身依赖于索引时间范围。
P4 如果不成立 → topic 的"实用性"比例受时间切片影响显著。

**已知污染**：写本文件时，已知原实验的中位倍数 ≈ 11,364、too_narrow = 73.4%。
这是上一轮的结果，不是本轮的数据。本轮不额外新增任何预测。

## 判据与阈值（写死）

- 三态分类规则和原实验完全相同：`title_phrase < 10` → `too_narrow`；三数任一非有限 → `error`；其余 → `measured`
- `title_phrase == 0` 绝不许进 measured（"没测着" ≠ "它没有"）
- 单调性违反率 > 5% 整轮作废
- API 失败率 > 5% 整轮作废
- ratio < 100 占比为 0 则整轮作废（指标无区分度）
- 分位数不给区间（和原实验一致）
- 比例报带有限总体校正（FPC）的 95% Wilson 置信区间

## 诚实边界

- 这是 **n=500 的随机样本**（占总体 11.1%），不是普查。所有比例带 FPC 区间。
- 测的是 OpenAlex 一家的检索行为，换 Scopus/WoS 结论可能不同。
- 全文口径的匹配机制没有公开文档，只测后果，不主张知道机制。
- 因 n 只有 500（原实验的50%），置信区间会比原实验宽，统计精度下降是预期内的。
- topic 的 display_name 不必然是研究者会输入的检索式（继承原实验的外部效度限制）。
- 改版原因：对照需要换语料时间切片 + 换种子；n 降为 500 是 API 预算限制，不是数据不好看。
