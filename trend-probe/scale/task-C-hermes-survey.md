# 任务：调研 OpenAlex 的免费替代文献检索源

## 背景

用户的 OpenAlex 账号刚被封禁，**不要再对任何 OpenAlex 域名（`api.openalex.org` 等）发起任何请求**，哪怕只是测试连通性也不行。

`trend-probe/scale` 这个探针原本用 OpenAlex 做"检索口径敏感度"实验：对同一个概念，用"全文宽松检索"和"标题短语精确检索"两种口径去查，看命中数差多少倍（测得中位数 11364 倍，85.7% 超过 1000 倍）。现在需要换一个免费、无需信用卡、最好不需要人工审核申请的文献/学术检索 API，来做同样性质的实验（换语料复现，检验这个"口径差异巨大"的现象是不是只在 OpenAlex 上才有）。

我们已经并行在用 **Crossref REST API**（`api.crossref.org`，完全免费、无需注册，礼貌池只需带 `mailto=` 参数）跑一版，这个不用你重复调研。

## 你的任务

调研 Crossref 之外，还有哪些**免费、无需信用卡**的文献检索/学术数据库 API 可以用来做类似实验（即：同一批检索词，能分别用"宽松/全文匹配"口径和"精确/标题匹配"口径去查、返回命中数量），重点关注：

1. **Semantic Scholar Academic Graph API**（`api.semanticscholar.org`）——是否免注册可用、有没有区分标题精确匹配和全文/关键词宽松匹配的参数、限流额度多大
2. **CORE API**（`core.ac.uk`）——是否需要申请 key、申请门槛高不高、查询参数能不能做类似口径区分
3. **PubMed / NCBI E-utilities**（`eutils.ncbi.nlm.nih.gov`）——免费无需 key（但建议带 email/tool 参数），查询语法（`[Title]` 字段限定 vs 全文本检索）是否能构造出等价的"宽松 vs 精确"两种口径
4. **DBLP API**——偏计算机科学，是否有类似口径区分能力（作为备选，覆盖面较窄）
5. 如果你知道其他免费、无需信用卡的候选（比如 Lens.org 的免费层、OpenCitations 等），也一并列出

对每个候选，给出：是否免注册/需要邮箱注册/需要审核申请、限流额度（每秒/每天大概多少次）、是否真的能区分"宽松口径"和"精确口径"两种检索方式、你的推荐排序。

**不要执行实际的 API 调用去测试**（避免消耗额度/触发限流影响后续正式实验），只依据你已知的公开文档信息给出调研结论；如果不确定某个细节，如实说"不确定，需要实测确认"，不要编造具体数字。
